# Wijzigingen 6 mei 2026

Overzicht van de UI/feature-wijzigingen van vandaag voor code review.

## Samenvatting

1. Groepslessen tonen nu de namen van deelnemende leerlingen (klikbaar).
2. Leerlingen overzicht toont aantal overeenkomsten en aanmeldingen, klikbaar naar detail.
3. Nieuwe pagina: `StudentDetail` (`/students/:userId`) voor admin/staff/developer.
4. Leerlingenportal (`MyStudentProfile`): toont nu eigen overeenkomsten en aanmeldingen.
5. Sidebar: leerlingen zien "Mijn profiel" bovenaan, dashboard verborgen voor leerlingen.
6. Handleiding (`/manual`) bijgewerkt met nieuwe Groepslessen-sectie en uitgebreide Leerlingen-sectie.

## Bestanden

### Nieuw
- `src/pages/StudentDetail.tsx` — detailpagina per leerling, geprotecteerd via `isPrivileged`. Laadt profiel + `lesson_agreements` (met teacher/lesson_type joins) + `lesson_signup_requests` (met `lesson_types(name)` / `lesson_groups(name)`).
- `src/components/students/SignupRequestItem.tsx` — herbruikbare rij voor een aanmelding (met klik naar dialog).
- `src/components/students/SignupRequestDialog.tsx` — detaildialog voor een aanmelding.
- `supabase/migrations/20260506181738_*.sql` — RLS/relatie updates voor `lesson_signup_requests` koppeling op email.

### Gewijzigd
- `src/App.tsx` — route `/students/:userId` → `StudentDetail`.
- `src/pages/Students.tsx` — kolommen "Overeenkomsten" en "Aanmeldingen" als klikbare buttons; naamkolom navigeert naar detail; ongebruikte imports verwijderd; biome-ignore voor mount-only effect toegevoegd.
- `src/pages/StudentDetail.tsx` — nieuwe pagina (zie hierboven).
- `src/pages/MyStudentProfile.tsx` — toont overeenkomsten en aanmeldingen; gebruikt `students.user_id` (PK) i.p.v. niet-bestaande `id` kolom.
- `src/pages/LessonGroups.tsx` — toont leerlingnamen per groep, klikbaar naar `/students/:userId`.
- `src/components/layout/Sidebar.tsx` — `isStudent = !isPrivileged && !isTeacher`; "Mijn profiel" bovenaan voor leerlingen; dashboard alleen voor niet-leerlingen.
- `src/pages/UserManual.tsx` — nieuwe sectie "Groepslessen"; uitgebreide sectie "Leerlingen" inclusief doorklikgedrag en leerlingportal.

## Reviewpunten

- **Roltoegang**: `StudentDetail` redirect niet-privileged users naar `/`. Verifieer dat staff-rol correct in `isPrivileged` valt.
- **Joins**: `students` PK is `user_id` — controleer dat alle nieuwe queries expliciet joinen op `user_id` (zie memory `database/query-relatie-patronen`).
- **RLS**: `lesson_signup_requests` koppelen op email — controleer of de policy een leerling alleen eigen aanmeldingen laat zien.
- **Sidebar**: dashboard nu verborgen voor leerlingen — bevestig dat route `/` voor leerlingen niets gevoeligs toont (of redirect).
- **Biome**: `bunx biome check` runt schoon op gewijzigde files (één bewuste `biome-ignore` in `Students.tsx` voor mount-only effect).

## Code opschoning

- Ongebruikte imports (`LessonAgreementItem`, `SignupRequestItem`) uit `Students.tsx` verwijderd.
- Eslint-disable comment in `Students.tsx` vervangen door biome-ignore.
- Biome auto-format toegepast op alle gewijzigde bestanden.
